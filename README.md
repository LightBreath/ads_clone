# Ads Clone

Open-source workspace for `chat-recreate`, a conversational ad recreation prototype.

- App code: [`chat-recreate/`](chat-recreate/)
- Local runtime docs: [`chat-recreate/README.md`](chat-recreate/README.md)
- Public demo: deployed from `chat-recreate/` through GitHub Pages

Compass credentials are intentionally not committed. Copy `chat-recreate/.env.example` to a local `.env` or export the variables in your runtime environment.
